1
Device Profiles define what gets tracked per kind. k8s-node gets cluster metrics, mac gets battery + sys, ios gets push-only battery/storage. New devices inherit the profile for their kind.
2
Collection model differs by kind: k8s-node is polled internally (already in cluster). Mac/linux run a lightweight Go agent (homelab-agent) that exposes /metrics — status API polls it. iOS is push-only: Scriptable + iOS Shortcuts automation POSTs every hour.
3
Company MacBook: tagged ownership: company, cleanup_on_offboard: true. Status API banner reminds you. make device-offboard macbook-work uninstalls the agent and removes the device from the registry.
4
Adding a new device: make device-add → prompts for name + kind → updates devices.yaml → prints the homelab-agent install one-liner for mac/linux, or the Scriptable push URL for iOS.
5
CO badge (company-owned) appears on widget row + detail screen. When device list grows, CO devices are grouped separately so it's clear what gets cleaned up.
